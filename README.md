# BFS-A-Medical-Diagnosis-Search
BFS &amp; A* Medical Diagnosis Search

This is how to run the Expert System

the code was written On google colab using python 3

First step:
The first thing you need to do is to install any libraries you don't have in your system 
to do that delete # from the first cell for the needed library
you only need to do this first time using the system

Second step:
Import all used libraries 
to do that just run the second cell
you need to do this every time you restart the system


Third step:
Building the Knowledge base 
to do this just run the cell under the title 'Building the knowledge base'
you need to do this every time you restart the system

Forth step:
Building the search system 
to do this for the Breadth First Search
just run the cell under the title 'building the Breadth First Search'
you need to do this every time you restart the system

Note : the cell under the Breadth First Search is just a test run no need to run it

to build the A* search run the cell under the title 'Building A* Search'
you need to do this every time you restart the system

Note : the cell under the A* Search is just a test run no need to run it 
and the cell after the test run with the title 'Getting heuristic using the same method used in search' is just to get the heuristic cost for documenting no need to run it.

Note the comparing cells are just to show time it needs to run no need to run it

Fifth step:
Implementing the system

for BFS just run the cell under the title 'Implementing Breadth First Search'
after that it will give you the option to check your symptoms form the checkboxes, you need to chose at least 3 symptoms for the search to work
after choosing the symptoms click the submit symptoms button in the end (the button will not show until you chose at least 3 boxes)

For A* search just run the cell under the title 'Implementing A*' 
after that it will give you the option to check your symptoms form the checkboxes, you need to chose at least 3 symptoms for the search to work
after choosing the symptoms click the submit symptoms button in the end (the button will not show until you chose at least 3 boxes)
